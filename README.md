# Tempa for GitHub Copilot

The Tempa plugin for the GitHub Copilot CLI and VS Code, with the `tempa` CLI inside (`bin/tempa.mjs`).

```sh
copilot plugin marketplace add Devleaps/tempa-copilot
copilot plugin install tempa@devleaps
~/.copilot/installed-plugins/devleaps/tempa/bin/tempa-launch login
```

This repository is release output: every Tempa release replaces its contents in one commit. Do not edit it
or open pull requests here.
